# Design Orbit — Creative Team Work Tracker

Internal reporting platform for the Webtree Creative Team. Replaces weekly Excel reporting with real daily work entry tracking and automated reporting.

## 🚀 Live Demo & Hosting
- **Production Application**: [https://design-orbit-sigma.vercel.app](https://design-orbit-sigma.vercel.app)
- **Database**: Supabase PostgreSQL

## 🛠 Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Backend & Auth**: Supabase

## 📖 Features
- Streamlined Daily Work Log with team designer filters
- Client Directory Management with quick inline creation
- Multi-Item Client Work Entry Form
- Weekly Review Meeting Presentation Mode
- Monthly & Overall Analytics with CSV Exports
- Change Password & Security Settings module with eye password toggles
